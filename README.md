# Film-ve-Dizi-Takip-Sistemi
Bu projenin amacı, kullanıcıların izledikleri veya izlemek istedikleri film ve dizileri düzenli bir şekilde takip etmelerini sağlamak.  Program sayesinde kullanıcılar yeni film ve diziler ekleyebilir, kayıtlı yapımları listeleyebilir, isimlerine göre arama yapabilir, izleme durumlarını güncelleyebilir ve istemedikleri kayıtları silebilir.
